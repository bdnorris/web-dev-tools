# App shell

Mode: Operate
Scope: Shell only. Existing tool jobs, inputs, copy, and interiors stay. Hash routes stay.

Audience: The maker, mid-task, one tool at a time.
Job: Get to a tool, copy a result, return to the work.
Constraint: Local-only. No accounts. Do not drop tools.

Chosen direction: Fold-out handle.
Memorable moment: Switching tools is unfolding an implement from a navy handle; the white sheet never becomes a different place.

## Direction contract

THESIS: One navy handle holds identity and nested tools; the active tool unfolds into a registered white sheet. Refuses a destination sidebar of seven pages.

OWN-WORLD: Chart Navy chassis, Chart Paper floor, white sheet. Flag Gold wordmark. Signal Red on the unfolded implement, Safety Orange tick and focus. IBM Plex Sans; Mono only inside tools. Square handle, 12px sheet.

STORY: You are at a bench. The handle is always there. You unfold one tool, copy, stay.

FIRST VIEWPORT: Full-height Chart Navy handle on the left (compact, square). Wordmark at the top in Flag Gold. Nested tool names stacked as implements; the active one is Signal Red with a 4px Safety Orange leading bar. The white sheet is docked flush to the handle (radius 0 12px 12px 0) and already shows the current tool. Primary action is inside the sheet (the tool’s own copy/commit).

FORM: Fold-out handle (bolder hand, dealt index 7). Seed key f4ef213d. Signature interaction: the sheet unfolds from the handle’s right edge (clip from left, ~200ms ease-out); reduced motion is an instant swap. Mobile: the handle folds to an edge stub; the same unfold opens the list, then the sheet.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
